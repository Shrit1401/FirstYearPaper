Scope: second-year CSE, semester 3 only. Prepared 17 September 2026.

NSM is provisionally interpreted as end-semester. No official midsem pattern was supplied; all papers use 30 marks and a suggested 90 minutes.

## Sources reviewed

Read the regular and makeup 2025-26 papers for CSS 2101, CSS 2102, CSS 2103, CSS 2104, and MAT 2101 (10 papers).
